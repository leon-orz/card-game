## 德州扑克网页游戏（card-game）

完成单机人机对战德州扑克网页游戏，位于 `c:\zone\2demo\card-game`。

**技术方案**：纯前端静态项目（无构建），文件结构：
- `index.html` — 页面骨架（设置/游戏/结算三屏 + 弹窗）
- `css/style.css` — 椭圆牌桌视觉（绿呢 + 木纹边框 + 卡片样式 + 响应式）
- `js/cards.js` — 洗牌、牌型判定（枚举 C(5~7,5) 组合）、Chen 起手牌力、翻牌后牌力
- `js/ai.js` — AI 决策（牌力 + 底池赔率 + 位置 + 随机 + 诈唬，normal/hard 难度）
- `js/game.js` — 游戏引擎 IIFE：盲注/轮流庄、四街下注轮、短全下、摊牌 min 结算、筹码守恒
- `server.js` — Node 静态服务器（`node server.js` → localhost:8080）

**关键实现细节（避免重复踩坑）**：
1. `placeBet` 公式：`add = clamp(target, p.bet+p.chips) - p.bet`，全下目标必须是 `chips + bet`（不是 chips）。
2. 翻牌前盲注在 beginStreet 外预缴，beginStreet 只在非 preflop 重置 bet。
3. 全下后由 `runoutNeeded()` 判定直接摊牌；盲注全下时对手仍可行动（跑牌前先判断）。
4. 弃牌结算必须置 `toAct=null` + `finishing` 标记，否则结果横幅期间按钮可点、重复结算会吞筹码。
5. `onBetRaise` 仅当加注超过对手 bet 时重置其 acted（短全下不重置）。
6. 摊牌结算：`mainPot = 2*min(handCommitted)`，差额返还多下注方。
7. `bestHand` 支持 5~7 张牌（翻牌/转牌阶段 AI 评估需要）。
8. 轮轴顺 A2345 已支持。
