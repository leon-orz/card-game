# 德州扑克 · 人机对战

单机运行的德州扑克网页游戏，玩家与电脑 AI 进行两人（heads-up）对战，虚拟筹码结算，支持多局连续对战直至一方筹码耗尽。

## 运行方式

无需构建，直接以静态页面打开：

```bash
node server.js
# 浏览器访问 http://localhost:8080
```

也可以直接把 `index.html` 用浏览器打开（本地 file 协议即可运行）。

## 功能特性

- **完整德州扑克规则**
  - 每人两张底牌，翻牌前 / 翻牌 / 转牌 / 河牌四轮下注
  - 公共牌逐步展示，摊牌时自动判定牌型并比牌
  - 支持全部十种牌型：高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺（含 A2345 车轮顺）
- **智能 AI 对手**
  - 依据起手牌力（Chen 公式）、翻牌后牌型强度、底池赔率、位置（庄家/盲注位）决策
  - 可执行弃牌、过牌、跟注、加注、全下，并带有随机波动与诈唬
  - 标准 / 激进两种难度可选
- **界面与交互**
  - 仿真实牌桌的椭圆形绿色桌布、木纹边框、牌桌式布局
  - 清晰展示双方手牌、公共牌、底池金额、双方筹码与当前街下注额
  - 下注操作按钮：弃牌、过牌/跟注（动态显示金额）、加注（滑杆调整）、全下
  - 庄家标记 D、行动提示、AI 决策气泡、结算横幅
- **对战进程**
  - 初始筹码、盲注级别、AI 难度可设置
  - 每手轮流坐庄，直至一方筹码耗尽显示战绩（对局数、胜局、最大底池）
  - 菜单支持继续游戏 / 重新开始本局 / 返回设置

```
card-game/
├── index.html        页面骨架
├── css/style.css     牌桌视觉样式
├── js/cards.js       牌堆、牌型判定与牌力评估
├── js/ai.js          AI 决策逻辑
├── js/game.js        游戏引擎、下注轮次、界面交互
└── server.js         本地静态服务器
```
